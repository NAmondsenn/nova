# Nova on the PC as a Proper App - Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Nova on the Windows PC gets a tray icon with a menu, a keyboard shortcut of its own, and the name "Nova" with the orb's icon wherever Windows shows it.

**Architecture:** The menu, the icon's state and the shortcut's text are plain Python with no Windows in them (`app_menu.py`, `shortcut.py`), which the Mac will reuse. A Windows-only tray (`tray.py`), on a thread of its own and made through ctypes like the orb's window, draws them and registers the shortcut. The satellite feeds it state it already has and acts on what's chosen; the brain adds one per-computer setting and three fields to the state it already sends. A small `Nova.exe`, compiled on the PC at install, runs the launcher and the satellite so Windows names the processes Nova.

**Tech Stack:** Python 3, ctypes (user32, shell32, kernel32), comtypes and numpy (both already on the PC), C# compiled by Windows' own compiler through PowerShell's `Add-Type`, pytest on the Pi.

**Spec:** `docs/superpowers/specs/2026-11-20-pc-app-design.md`

## Global Constraints

- Nothing new to install on the PC or the Pi. If Task 2 shows there's no other way, stop and ask him.
- The tray exists only on a push-to-talk satellite on Windows (`satellite.push_to_talk and _on_windows()`); everywhere else nothing is made and nothing from Win32 is imported.
- A press, the chime, a reply or music never waits on the tray, the menu or the shortcut, and never fails because of them. Every call into the tray returns at once; a failure in it is logged once and it goes quiet. Numpad 3 (the press listener) is untouched.
- No console window ever shows: every child is started with `CREATE_NO_WINDOW`, and `Nova.exe` is a windowed program.
- After Quit there is no Nova process and no tray icon, and nothing starts it until the next logon or the Start menu. Never two Novas.
- Names in settings, messages and code say "computer" and "shortcut", never "PC" or "Windows" (Windows-only modules apart).
- Exact values: default shortcut `ctrl+alt+n`; menu labels `Listen`, `Play`, `Pause`, `Play / Pause`, `Next`, `Mute microphone`, `Settings`, `Start with Windows`, `Restart Nova`, `Quit`; hover texts `Nova`, `Nova: microphone muted`, `Nova: not connected`; icon sizes 16, 20, 24, 32, 48, 256; exit codes `QUIT_CODE = 10`, `RESTART_CODE = 11`; the page opens at `<address>#satellites`.
- Deploys, pushes, restarts of `nova-backend` and anything run on his PC are his named jobs: give him the sentence and wait. Anything that will sound in his room is announced first. He sees the finished icons before they go live.
- Code style: the repo's - full-sentence comments saying why, British spelling, " - " dashes, Google-style docstrings, one commit per task, a test that fails on the old code.
- Tests (`PT` below): `NOVA_TREE=/home/nathaniel/work/Home-Assistant-app NOVA_CHECK=app bash ~/work/Home-Assistant/.superpowers/tools/pi_test.sh <args>`. On CT 109: check `cat /proc/loadavg` first (wait if above 3), prefix with `nice -n 19 timeout 600`, one run at a time, no repeat runs. Never `ps` on the Pi. No `git stash`.
- Before Task 1: bring `pc-app` up to the tip of `screen-indicator` (or of `origin/main`, if the orb has merged by then). The ledger is `.superpowers/sdd/2026-11-20-pc-app/progress.md`.

### Task 5: The tray

**Files:**
- Create: `voice_assistant/tray.py`
- Test: `tests/test_tray.py`

**Interfaces:**
- Consumes: `app_menu.AppState`, `items`, `icon`, `hover`, `Item`, `SEPARATOR`; `shortcut.Shortcut` (Task 3); the icon files (Task 1).
- Produces:
  - `class Tray(read_state: Callable[[bool], AppState], on_choice: Callable[[str], None], on_shortcut: Callable[[], None], on_taken: Callable[[bool], None], icons: str, backend: Optional[Callable[[], object]] = None)`
    - `read_state(opening)` is called on the tray's thread: with `True` just before the menu is drawn, `False` otherwise.
    - `available: bool` - whether the icon could be made.
